# Spaced repetition

Spaced repetition is reviewing something at increasing intervals — right before
you'd otherwise forget it — instead of cramming it all at once. It's the single
highest-leverage habit in my [second brain](second-brain.md): capture is cheap,
but a note I never revisit may as well not exist.

## Why it works

Memory fades on a predictable curve. Each well-timed review flattens that curve,
so the same fact costs less effort to retain over time. Two effects do the work:

- **The spacing effect** — the same total study time produces stronger memory
  when it's spread out rather than packed together.
- **Retrieval practice** — the act of *recalling* a note (not re-reading it)
  is itself what strengthens it. Effortful recall beats passive review.

## How I use it in this vault

I don't run flashcard software for everything. For ideas, the lightweight
version is enough:

1. When I promote a capture from the [inbox](../inbox.md) into an evergreen
   note, I add it to the review rotation in my weekly pass.
2. During the weekly review I open the [reading map of content](../moc/reading.md),
   try to recall each linked note *before* opening it, then read to check.
3. Notes I can recall cleanly get reviewed less often; the shaky ones come back
   sooner.

The trick is to test recall, not just re-read. Re-reading feels productive and
mostly isn't.
