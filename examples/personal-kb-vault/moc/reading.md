# Reading — map of content

A **map of content** (MOC) is a hub page. It doesn't hold the ideas itself — it
links out to the notes that do, so related thoughts stay one click apart instead
of scattered across folders. This is the hub for everything I read and the notes
it spawns.

## Core notes

- [Building a second brain](../notes/second-brain.md) — the system these reading
  notes feed into: capture, link, review.
- [Spaced repetition](../notes/spaced-repetition.md) — how I make sure a note I
  read actually sticks.
