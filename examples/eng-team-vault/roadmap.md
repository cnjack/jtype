# Product Roadmap

Kept private (`publish: false`) — this is our working plan, not a public page.

## Q3

- **Ship the MCP server** — the foundational milestone; unblocks every AI
  integration. Finalize the tool surface and OAuth flow this quarter.
- **Public launch of the AI integration** — depends on the MCP server landing.
  Docs, demo assets, and the blog post ramp in parallel.

## Q4

- Mobile app — read-first, then quick capture into the default vault.
- Custom domains polish — onboarding flow + TLS automation.

## Out of scope (for now)

- Real-time collaborative editing in a single note.
- Plugins / third-party extensions.

See the live work on the **Launch** board and in
[projects/launch.md](projects/launch.md).
