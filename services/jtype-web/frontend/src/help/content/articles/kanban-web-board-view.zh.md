你在工作区里创建的看板，会在网页应用中真正活起来。这里是你推进工作、实时看到队友动态、并把一块繁忙的看板裁剪成只剩你关心内容的地方。如果你完全没接触过看板，请先阅读[看板与卡片](/help/c/kanban/boards-and-cards)——本文讲的是*使用*看板，而不是搭建看板。

## 打开看板

登录网页应用并选择你的工作区，然后进入**看板（Kanban）**区域。你的看板都列在那里；点击其中一个即可打开。你会看到从左到右排列的纵向泳道——**To do**、**Doing**、**Done**，以及你自己添加的泳道——每个泳道里都叠着一摞卡片。

点击任意卡片，会在侧边打开**卡片详情 Sheet**。看板仍然可见，进入详情前的滚动位置、选择、筛选以及获得焦点的卡片都会被记住；关闭 Sheet 或从关联卡片返回时，会恢复这些上下文与键盘焦点。编辑者可以修改标题、排期、状态、优先级、负责人、标签、关系、附件、提醒、归档状态和 Markdown 描述；只读成员看到相同上下文，但不会看到变更控件。

## 在泳道之间拖拽卡片

推进工作只需拖一下。按住一张卡片并拖动它：

- 在状态泳道内**上下**拖动以重新排序，
- **横向**拖到另一个泳道以改变当前选择的字段。

状态泳道中的横向拖拽会更新 `status`；优先级泳道更新 `priority`；负责人泳道更新 `assignee`；自定义泳道更新稳定的 `swimlane` ID。JType 会立即保存。状态移动在底层与 `jtype card move --board B <card> --to-column C` 是同一个操作。

## 管理状态工作流

状态是 JType 看板默认的泳道。在**泳道（Swimlanes）**控件旁打开**管理状态**，可以添加、重命名、排序、改色或删除状态，也可以设置 WIP 上限以及指定哪个状态代表完成。

每个状态都有稳定的内部 ID。例如，把 **Doing** 重命名为 **In progress** 只会改变显示名称，卡片仍然保留在原状态中。删除仍有卡片的状态时，确认框会明确显示它们将自动迁移到的第一个剩余状态；如果该 fallback 不符合你的工作流，请取消操作。

## 实时更新

看板是实时的。当队友移动一张卡片、重命名一列或编辑某段描述时，你的看板会自动更新——无需刷新。每一次变更都通过实时连接推送，并在片刻之内落到该工作区中所有打开着的看板上。

你自己的操作绝不会以闪烁的形式回弹给你：看板知道哪些变更是你做的，并会悄悄跳过它们，因此你只会看到*别人*的编辑到来。如果你的连接断开，看板会在重新连上的那一刻重新加载权威状态，所以你永远不会基于一份过时的视图去操作。

> 提示：在两块屏幕上打开同一个看板——比如你的笔记本和会议室显示屏——然后在其中一块上拖动一张卡片。它几乎会立刻在另一块上移动。这正是实时层在发挥作用。

## 筛选、排序、排列与搜索

一块真实的看板会变得拥挤。列上方的工具栏提供了多种聚焦方式，而且它们可以叠加使用：

- **筛选（Filters）**——组合多个优先级、负责人、标签、截止日期范围、被阻塞卡片以及**我的卡片**。同一分组内匹配任一已选值，不同分组之间需要同时满足。
- **排序（Sort）**——在每个泳道内对卡片排序，例如按优先级或截止日期。
- **泳道（Swimlanes）**——选择唯一的纵向维度：状态（常规工作流）、优先级、负责人或自定义。
- **管理**——状态泳道管理工作流；自定义泳道具有稳定 ID，可编辑名称、颜色与顺序。优先级或负责人泳道也可以转换为可编辑的自定义泳道。
- **搜索（Search）**——输入关键字，快速缩小到标题或正文匹配的卡片。

启用的筛选会显示为可单独移除的标签，筛选面板也会显示当前可见卡片数。你可以在**看板**、**表格**、**日历**、**Backlog** 与 **Gantt** 之间切换，而不会复制出第二套工作数据。筛选和搜索都在浏览器中即时执行，只改变*你自己*看到的内容，不会移动任何卡片。JType 还会为当前看板持久化你的视图、范围、分组、排序、筛选与折叠状态；这些偏好不会改写共享 `.board` 文件。

## My Work 与 Inbox

选择 **My Work**，会投影出当前项目中分配给你的卡片。选择 **Inbox**，会显示从同一批卡片推导出的可行动信号：`@mention`、到期提醒、今天截止或已逾期的工作，以及仍被依赖项阻塞的本人卡片。忽略 Inbox 项只影响同一设备上的个人视图；底层 mention、日期或依赖发生变化后，会产生新的信号。

## 批量变更

选择多张卡片后，可以一次设置负责人、标签、截止日期或归档状态。选择工具栏会明确显示受影响卡片数，只读成员不会看到变更操作。如果某项操作失败，JType 会显示失败信息并保留选择，方便重试，而不会伪装成整批成功。

## 字段级 Activity

**Activity** 标签页会说明具体变更，而不仅是展示不透明的保存版本。每条记录可以包含字段的 before/after，以及由服务端确定的 actor、client 与 token 标签，例如“ Maya 把状态从 To do 改为 Doing · Web”，或“发布 agent 添加了 `blocked` 标签 · MCP · nightly-triage”。原始 token、token hash 与 fingerprint 永远不会显示。没有结构化事件的旧卡片会回退到版本历史。
