你在工作区里创建的看板，会在网页应用中真正活起来。这里是你推进工作、实时看到队友动态、并把一块繁忙的看板裁剪成只剩你关心内容的地方。如果你完全没接触过看板，请先阅读[看板与卡片](/help/c/kanban/boards-and-cards)——本文讲的是*使用*看板，而不是搭建看板。

## 打开看板

登录网页应用并选择你的工作区，然后进入**看板（Kanban）**区域。你的看板都列在那里；点击其中一个即可打开。你会看到从左到右排列的列——**To do**、**Doing**、**Done**，以及你自己添加的列——每一列里都叠着一摞卡片。

点击任意卡片，会在侧边打开**详情面板（peek）**。这是一个可调整宽度的详情视图，你可以在不离开看板的情况下编辑标题、状态、优先级、负责人、截止日期、标签以及 Markdown 描述。

## 在列之间拖拽卡片

推进工作只需拖一下。按住一张卡片并拖动它：

- 在同一列内**上下**拖动以重新排序，
- **横向**拖到另一列以改变它的状态。

当你松开卡片时，JType 会立即保存这次移动，并压实顺序，确保没有空隙。在底层，这与 `jtype card move --board B <card> --to-column C` 是同一个操作——看板视图只是给了你一种用指针拖拽的方式来完成它。

## 实时更新

看板是实时的。当队友移动一张卡片、重命名一列或编辑某段描述时，你的看板会自动更新——无需刷新。每一次变更都通过实时连接推送，并在片刻之内落到该工作区中所有打开着的看板上。

你自己的操作绝不会以闪烁的形式回弹给你：看板知道哪些变更是你做的，并会悄悄跳过它们，因此你只会看到*别人*的编辑到来。如果你的连接断开，看板会在重新连上的那一刻重新加载权威状态，所以你永远不会基于一份过时的视图去操作。

> 提示：在两块屏幕上打开同一个看板——比如你的笔记本和会议室显示屏——然后在其中一块上拖动一张卡片。它几乎会立刻在另一块上移动。这正是实时层在发挥作用。

## 筛选、排序、分组与搜索

一块真实的看板会变得拥挤。列上方的工具栏给了你四种聚焦方式，而且它们可以叠加使用：

- **筛选（Filter）**——只显示匹配优先级、负责人、标签或截止日期的卡片。
- **排序（Sort）**——在每一列内对卡片排序，例如按优先级或截止日期。
- **分组（Group）**——把整块看板按状态、优先级或负责人重新分组。
- **搜索（Search）**——输入关键字，快速缩小到标题或正文匹配的卡片。

如果你更习惯把所有内容当作一行行扫描而不是泳道，还有**表格（Table）**视图可用。以上所有操作都在你的浏览器中即时完成，而且是个人化的：筛选或分组只改变*你自己*的视图——它绝不会移动任何人的卡片，也不会影响队友看到的内容。你的视图偏好会按看板分别记住，所以下次打开时看板还是你离开时的样子。
