**仓库**是你笔记的家——它就是设备上一个普通的 Markdown（`.md`）文件夹。本文将带你打开一个仓库、写下第一条笔记，并试用三种编辑模式。这里的所有操作都不触及云端；每一次按键都落进一个你完全拥有的纯文本文件里。

## 打开或创建仓库

在欢迎界面，任选其一：

- **使用默认仓库**——JType 会创建并打开 `~/Documents/.jtype`。如果你只想马上开始写作，这是最佳选择。
- **打开仓库**——选择任意一个已有文件夹。如果里面已经有 `.md` 文件，JType 会原样读取它们。你那些 `meetings/`、`projects/` 之类的文件夹会原封不动地留在原处。

已经进入应用了？随时可以用**文件 → 打开仓库**切换到另一个文件夹。

> 文件夹*本身*就是唯一可信来源。没有导入或导出这一步——用任何其他编辑器打开同一个文件夹，你的笔记就在那里。

## 仓库主页 vs. 单文件模式

JType 有两种工作方式，它们的外观刻意不同：

- **仓库模式**是完整体验：可浏览的文件树、按名称跳转的**快速打开**、编辑器、**分栏预览**、文档信息、发布检查，以及（登录后的）账号与云端同步。
- **单文件模式**是面向单个 `.md` 文件的专注编辑器，没有同步、账号或发布相关界面。从欢迎界面的**打开 Markdown 文件**进入。它非常适合快速修改一个不属于任何仓库的文件。

当你打开了仓库但还没选定文档时，看到的是**仓库主页**——一个平静的着陆点，而不是一个变灰的编辑器。

## 写下第一条笔记

在仓库模式下，新建一条笔记，取个像 `welcome.md` 这样的名字。输入一些 Markdown：

```markdown
---
title: Welcome
---

# 欢迎来到我的仓库

这是我的第一条 **JType** 笔记。它是磁盘上的一个纯
Markdown 文件——我可以用任何编辑器打开它。

- [ ] 试试分栏预览
- [ ] 以后发布点东西
```

顶部的 `---` 区块是 **YAML frontmatter**——关于笔记的可选元数据。之后你会用它来发布（`publish: true`）和设置页面信息。语法详见[撰写 Markdown](/help/c/vault-editing/writing-markdown)。

## 写作、分栏与预览

编辑器有三种模式，可从工具栏切换：

| 模式 | 你看到的内容 |
|---|---|
| **写作** | 仅显示 Markdown 源码——无干扰地输入。 |
| **分栏** | 左边是源码，右边是实时渲染的预览。 |
| **预览** | 完全渲染后的笔记，正如读者看到的那样。 |

从**写作**开始，切到**分栏**一边输入一边看格式渲染，最后用**预览**做一次通读。用**快速打开**按名称在笔记间跳转，双手始终不离键盘。

## 你的文件始终在磁盘上

你刚才做的一切，都写进了文件夹里真实的 `.md` 文件。你可以：

- 用你平常备份文件的方式备份这个文件夹，
- 在另一个应用里编辑同样的笔记，
- 完全离线地继续工作。

当你准备好把笔记带到另一台设备或与同事共享时，把仓库绑定到云端工作区即可——参见[云端工作区与绑定](/help/c/sync-workspaces/cloud-workspaces)。想理解整个模型，请阅读 [JType 的工作方式](/help/c/getting-started/the-jtype-flow)。
