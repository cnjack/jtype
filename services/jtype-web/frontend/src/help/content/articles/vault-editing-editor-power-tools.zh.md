JType 的编辑器刻意保持「纯 Markdown」——你输入的内容就是 `.md` 文件里的内容。在这个核心之上，一组进阶工具消除了日常写作的摩擦。本页介绍 slash 菜单、查找替换、图片粘贴、可点击大纲，以及预览的渲染能力。

## Slash 菜单

在**行首**输入 `/`，光标处会弹出一个插入菜单。继续输入即可过滤（`/tab` 能找到*表格*），用 ↑/↓ 选择，回车插入，Esc 关闭。

可插入的块：一至三级标题、无序 / 有序 / 任务列表、引用、代码块、表格、数学公式块、Mermaid 图、看板嵌入和分隔线。触发仅限行首，所以行中的 URL 和文件路径不会误弹菜单。

## 查找替换

- **Cmd/Ctrl+F** 打开查找。回车 / Shift+回车（或 Cmd+G / Cmd+Shift+G）在匹配间跳转。
- **Cmd/Ctrl+Alt+F** 直接展开替换行，也可以点搜索框旁边的箭头。
- **Aa** 切换大小写敏感。
- **Replace** 替换当前匹配；**All** 一步替换全部。两者都走正常编辑管线，Cmd+Z 撤销照常可用。

替换仅在写作模式下可用。预览 / 分屏模式中查找会高亮渲染后的文本——渲染文本和 Markdown 源码并非一一对应，因此有意禁用了从这些视图发起的替换。

## 从剪贴板粘贴图片

复制一张截图或图片，直接粘贴进编辑器（桌面端）。JType 会把文件保存到文档旁的 `assets/` 目录，并在光标处插入链接：

```markdown
![pasted-20260716-101530-x4f2.png](assets/pasted-20260716-101530-x4f2.png)
```

预览会自动解析 vault 相对路径的图片；如果 vault 已绑定云工作区，图片会像其他资产一样同步。Web 端编辑器粘贴图片则会上传到工作区资产存储，同样插入链接。

## 可点击大纲

文档信息面板的**大纲**列出所有标题。点击即可跳转——写作 / 分屏模式下光标落到标题行；预览模式下滚动到对应章节。

## 更丰富的预览

预览（和分屏）现在渲染的不只是纯 HTML：

- **代码高亮** —— 带语言标注的代码块（` ```ts `、` ```python ` 等）会被高亮。每个代码块悬停时出现**复制**按钮。
- **图片放大** —— 点击预览中的任意图片全屏查看；再点一次或按 Esc 关闭。
- **HTML 实时预览** —— ` ```html ` 代码块会在完全沙箱化的框架内渲染内容（脚本不会执行）。用块上的 **Preview / HTML** 标签在渲染结果和高亮源码之间切换。

这些能力在导出 PDF 时也会合理生效：代码保留高亮，交互元素（复制按钮、标签页）不会出现在导出结果里。
