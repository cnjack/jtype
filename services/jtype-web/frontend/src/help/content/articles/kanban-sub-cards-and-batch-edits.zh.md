当项目卡片多起来之后，你需要这三件工具：拆解大任务的子卡片、批量编辑的多选，以及能搜索卡片内部（而不只是标题）的搜索框。

## 子卡片

任何卡片都可以通过把 `parent` frontmatter 指向父卡的相对路径（去掉 `.md`）成为**子卡片**：

```markdown
---
title: 设计登录表单
board: roadmap
status: todo
parent: [[roadmap/login-epic]]
---
```

一般不需要手写：

- 在卡片的侧边详情里，从 **Parent** 下拉选择父卡。
- 或者用父卡详情里的 **Sub-cards** 区：在 *"+ Add sub-card"* 输入标题，JType 会在第一列创建卡片并自动设好 parent。
- CLI：`jtype card create --board roadmap --status todo "设计表单" --parent roadmap/login-epic`；之后也可以用 `jtype card set <path> --parent roadmap/login-epic` 重新指定（空字符串解除）。

旧的纯文件名引用（例如 `[[login-epic]]`）在名称唯一时仍然兼容。新写入的路径引用可以避免不同文件夹中存在同名卡片时，把子卡错误地绑定到另一个父卡。

卡片一旦有了子卡，卡面就会显示**完成度圆环**——已完成/总数，子卡位于看板的完成列即计为完成。父卡详情列出所有子卡及其状态，点击即可跳转。

子卡片就是普通卡片：出现在各自的列里、照常移动和过滤。层级关系就是一个诚实的 frontmatter 字段——在 Markdown 里可见、随处同步、AI 工具也能读。

## 批量编辑

**Cmd/Ctrl+点击**卡片可多选（选中的卡片带高亮描边）。底部会浮出工具条：

- **Status…** 把所有选中卡片移到某一列。
- **Priority…** 统一设置优先级。
- **Delete** 一次确认后把整个选择移入回收站。
- **Esc** 或 ✕ 清除选择。

Cmd+点击已选中的卡片会将其移出选择。批量编辑和单卡编辑走同一条保存路径，云同步和看板 webhook 都能看到每一次变更。

## 卡片全文搜索

看板搜索框现在不只匹配标题。查询会命中卡片的**标题、工单号、负责人、标签和 Markdown 正文**。搜索可以与过滤、分组组合使用——「所有提到 `payments` 且仍由 Maya 负责的卡片」就是一次搜索加一个过滤条件。
