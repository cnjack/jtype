每张卡片的侧边详情里都有**评论**区——在不修改卡片描述的情况下讨论工作。评论是云端功能：存在工作区里（不在 `.md` 文件中），卡片的 Markdown 保持干净，而讨论历史始终跟随卡片。

## 撰写评论

评论框支持 **Markdown**——加粗、列表、任务项、代码，甚至图片。按 **Cmd/Ctrl+Enter** 发送。悬停自己的评论会出现 ✎ **编辑**和 ✕ **删除**按钮；编辑过的评论带一个小小的 *edited* 标记。工作区管理员可以删除任何评论，但没有人能改写别人的话。

## 话题与回复

点评论上的 ↩ **回复**按钮即可在其话题内回应。话题刻意只有一层——回复「回复」仍会落在同一话题里，讨论不会变成金字塔。删除话题的根评论会移除整个话题。

## 表情回应

😊 按钮展开一排 emoji（👍 ❤️ 🎉 😄 👀 ✅）。点击即回应；再点同一个 emoji 撤回。回应气泡显示数量，你参与过的气泡会着色。

## 解决讨论

当一个话题完成使命后，点根评论上的 ✓ **解决**按钮。整个话题会折叠成安静的一行——*Resolved · 评论首行*——让长期存在的卡片保持可读。点击折叠条可重新展开，话题重开时也可以取消解决。

## 评论在哪些地方可用

- **Web 看板**：完整评论功能，始终可用。
- **桌面看板**：当 vault 绑定了云工作区且同步开启时，桌面端卡片详情显示同样的话题，并可发评论、回应、解决。未绑定（纯本地）的 vault 没有评论——没有云端可以存放它们。
- **AI 工具**：通过 MCP 连接的 agent 也能读写卡片评论（`list_card_comments`、`comment_card`、`resolve_card_comment`）——很适合把 review 结论直接留在被审查的卡片上。
