Maya 是一名产品研究员，她读得很多——论文、博客文章，还有洗澡时冒出来的半成形念头。多年来，她的笔记散落在三个应用里，没有一个让她完全信任。真正想留下的想法被埋没了，而她用的工具随时可能停服（或者涨价）。

她想要一个统一的地方：写起来够快、想法之间容易串联，而且**真正属于自己**——这些文件可以用任何编辑器打开，可以按自己的方式备份，永远不需要"导出"。于是她用 JType 搭建了一个完全本地优先的个人知识库。

## 她面对的问题

这件事的核心不是"存文档"，而是**长期地把思考写出来**：在想法刚冒头时立刻捕捉，把它和已知的东西连起来，过段时间再回来时这些联系依然成立。让个人知识库失败的摩擦总是同一个：捕捉太慢，想法落不了地；就算落了地，彼此不互联，也会慢慢腐烂。

Maya 的两个要求很简单：

- **捕捉必须是瞬时的**——既能从桌面应用里写，也能在工作时直接从终端写。
- **笔记要活得比工具久。**纯 Markdown 存在自己的磁盘上，随处可开，没有任何锁定。

## 仓库结构

JType 仓库就是一个装着 Markdown 文件的文件夹，所以 Maya 的结构完全按她自己的习惯来——没有固定模式，也没有数据库。她的结构是这样的：

```text
personal-kb-vault/
  README.md                  这个仓库如何组织
  inbox.md                   快速、未整理的捕捉
  daily/
    2026-06-14.md            今天的日志
  notes/
    second-brain.md          常青笔记  ─┐ 彼此
    spaced-repetition.md     常青笔记  ─┘ 互相链接
  moc/
    reading.md               内容地图：阅读主题中枢
  .jtype/
    cloud.json               可选的云端绑定（由 `jtype bind` 创建）
```

`inbox.md` 是大杂烩收件箱。`daily/` 按天存放带日期的日志。`notes/` 存放**常青笔记**——每篇只讲一个想法，随时间不断打磨。`moc/` 存放**内容地图**（map of content）：作为中枢的页面，向外链接到相关笔记，让任何东西都不会丢失。

## 她的工作流

**1. 捕捉——不打断心流。**当想法在做事中途冒出来，Maya 不切换应用。笔记命令是本地优先的：它们直接写入当前文件夹里的 Markdown 文件。

```bash
# 一行命令直接写进收件箱
jtype note create inbox.md --content "间隔效应 > 临时抱佛脚。和复习节奏挂钩。"

# 把别处的长内容通过管道传进来
pbpaste | jtype note create notes/reading-queue.md - --title "阅读队列"
```

这些命令无需服务器、无需登录就能运行——文件本身就是事实来源。捕捉会变成真实的 Markdown，她可以在桌面应用里立刻打开。

**2. 链接——把零散捕捉织成想法之网。**在每日回顾时，Maya 把最好的捕捉提升为 `notes/` 下的常青笔记，并用普通的 Markdown 链接把它们连起来。`second-brain.md` 链接到 `spaced-repetition.md`，反之亦然；两者都被 `moc/reading.md` 这个中枢链接。这些联系就是 `[文字](路径)` 链接——可移植，并且在快速打开中可点击。

**3. 回顾——每周一次，用分屏模式。**每个周日，她在桌面编辑器的分屏视图里打开 `moc/reading.md`（左边写、右边预览），顺着链接走一遍，并清空收件箱。文档信息会告诉她哪些笔记在生长、哪些已经变旧。

**4. 发布（可选）——一份周报。**当某篇笔记值得分享，她就在它的 YAML frontmatter 里加上 `publish: true`。这篇笔记就成为她公开站点 `/u/maya` 上的一个页面，而源文件仍然是仓库里的纯 Markdown。没有这个标记的内容则完全保持私密。

**5. 同步（可选）——在手机上读。**她曾运行过一次 `jtype bind --workspace personal-kb`，把仓库映射到一个云端工作区。现在 `jtype sync` 会把本地修改推上去，并把她在别处捕捉的内容拉下来——后写覆盖先写，省心。她的笔记本电脑仍是事实来源，云端只是一个镜像。

## 结果

捕捉从"我待会儿再记"（也就是永远不记）变成了一行终端命令。过去会蒸发的想法，现在几秒内就落进 `inbox.md`，并在每周 15 分钟的回顾里被编织进常青笔记。内容地图让她总能找回某个想法的来路。

而且因为这一切都是自己磁盘上的纯 Markdown，这个知识库并不绑定 JType 的未来——它绑定的是她自己的未来。

> 这个示例仓库随仓库代码提供，位于 `examples/personal-kb-vault`。在 JType 里打开那个文件夹，就能用真实文件跟着 Maya 的流程走一遍。
